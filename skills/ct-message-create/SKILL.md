# Core message (Thông điệp lõi)

A method by Cuong Thach. Full source: https://cuongthach.com/docs/content-system/idea-write-edit/guides/how-to/create-a-core-message/ (Vietnamese: https://cuongthach.com/docs/vi/content-system/idea-write-edit/guides/how-to/create-a-core-message/). When this skill and the docs disagree, the docs win.

Reply in the user's language. It is the first job of the Idea step of **Idea - Write - Edit** (Ý - Viết - Sửa).

## What it is

**One sentence** readers must remember after the post. One post carries exactly one. It holds the customer, their problem and the writer's solution, and nothing else: no story, no feature list, no call to action. It is the filter for the outline, **never a section of the post**.

On a sales page it is the second line, under the product name: who it is for, what result, by which solution of the seller's.

## Before you start

Check the three root questions with the user: **What is it? How does it work? Why does it matter?** If they cannot answer them, stop: the topic is not ready. Do not search the web or suggest solutions: the solution must be theirs.

## Three steps

1. **Pick one idea seed.** Lay out every idea the user has and pick exactly one for this post. The rest go on a "save for other posts" list, never deleted.
2. **Answer the three questions of context.** Ask the user, one at a time, and write down their answers in their words:
   - **Customer, in their own words.** For each expert word ask: would the customer say this? If not, swap it.
   - **Problem.** One pain tied to this idea, written at three levels: outside (what people can see), inside (the feeling, shown through pictures without naming the emotion), root (the wrong belief).
   - **Their own solution.** A view, formula or process from real experience, and where it takes the customer. Rough is fine.
   Mark any answer they do not have yet with `?`. **Never fill a gap by guessing.**
3. **Squeeze it into one sentence and a title.** Which problem the customer is stuck in, what the solution is, where it takes them. Add a short title that says exactly that, with no fancy words and no metaphors. You may offer a few wordings; the user chooses.

## Four checks

Read the sentence and ask. Each "no" sends you back:

| Question | If it fails |
|---|---|
| Does it have only one main idea? | Back to step 1, split into two posts |
| Can someone outside the field understand it without explanation? | Back to the customer question, change the words |
| Could another post online say this exact sentence? | Back to the solution question, add the user's own experience |
| Has the user said this message in an older post? | Link to it, sharpen the new angle, or update the older post instead |

When all four pass, that sentence is the core message. Keep it next to the outline: every idea that stays must serve it, and the title, the description, the opening and the main content must all say the same thing.

## When it falls short

- **Long but forgettable:** four or five messages. Split into several posts.
- **Words readers do not know:** translate expert language into the customer's words.
- **Too many personal stories:** keep only those that touch the chosen pain.
- **No way out:** the solution is missing. Ask the user for it.
